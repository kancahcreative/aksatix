Status sekarang: penyimpanan browser.
CRUD di dashboard ini benar-benar bekerja dan tersimpan pada browser yang sama. Data tidak otomatis tersedia di browser admin lain atau halaman website utama.

Untuk operasional produksi

  1. Buat database untuk events, ticket_types, orders, order_items, attendees, organizers, coupons, dan admin_users.
  2. Gunakan autentikasi admin dengan role dan permission di server.
  3. Hubungkan dashboard dan website publik ke API yang sama.
  4. Proses pembayaran melalui payment gateway dan webhook terverifikasi; jangan mengubah pesanan menjadi lunas hanya dari browser.
  5. Tambahkan audit log, validasi QR/check-in, backup, dan kebijakan refund.
